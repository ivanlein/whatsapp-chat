# WhatsApp Chat

This service allows you to write text messages for WhatsApp and receive responses from WhatsApp chat directly in the dialogue window on the website

# How to use:

To use you will need to create an instance on the Green API website:

1. Green API: https://green-api.com/
   
2. How to create an instance: https://www.youtube.com/watch?v=AZ-Lbuk_E8Q

_____________________________________________________________________________________________________________________________________________________________________________________________________________________

After creating the instance, you can use the site's capabilities, go to the site:

WhatsApp Chat website link: https://ivanlein.github.io/whatsapp-chat/

1. Enter your idInstance
   
2. Enter your apiTokenInstance

3. Enter the phone number specified in the contact instance you want to write to
  
!IMPORTANT!

The phone number must be in the format +7... but without the "+" sign
