# WhatsApp Chat: logic description

# App.js

Это корневой компонент приложения, который управляет отображением либо формы аутентификации (AuthForm), либо чата (Chat).

Состояние:

1. authData: Состояние, которое хранит данные аутентификации (объект с полями idInstance, apiTokenInstance и recipientPhone).

Если authData равно null, это означает, что пользователь еще не прошел аутентификацию.



Функция handleAuth:

Эта функция вызывается при успешной отправке формы аутентификации.

1. data: Объект с данными аутентификации, переданный из компонента AuthForm.

2. setAuthData(data): Обновляет состояние authData, что приводит к отображению компонента Chat.



Рендеринг:

Условный рендеринг:

1. Если authData равно null, отображается компонент AuthForm с пропсом onAuth, который передает функцию handleAuth.

2. Если authData не равно null, отображается компонент Chat с пропсами idInstance, apiTokenInstance и recipientPhone, переданными из authData.

# Chat.jsx

Функция sendMessage:

1. Эта функция отправляет сообщение через API Green API.

2. Проверка текста: Если текст пустой, функция завершается.

3. Формирование запроса:

4. URL: Используется для отправки сообщения через API Green API.

5. payload: Объект с полями chatId (ID чата) и message (текст сообщения).

6. Отправка запроса: Используется axios.post.

7. Обновление состояния: После успешной отправки сообщение добавляется в массив messages с флагом isMyMessage: true.



Функция receiveMessages:

1. Эта функция проверяет наличие новых входящих сообщений через API Green API.

2. Получение уведомлений: Используется axios.get для получения уведомлений.

3. Проверка типа уведомления: Если уведомление — это входящее текстовое сообщение (incomingMessageReceived и textMessage), оно добавляется в массив messages с флагом isMyMessage: false.

4. Удаление уведомления: После обработки уведомление удаляется с помощью axios.delete.



Хук useEffect:

1. Интервал: Каждые 5 секунд вызывается функция receiveMessages для проверки новых сообщений.

2. Очистка интервала: При размонтировании компонента интервал очищается.



Рендеринг:

1. messages.map: Отображение всех сообщений с помощью компонента Message.

2. InputBox: Компонент для ввода текста, который вызывает sendMessage при отправке.

# Message.jsx

Пропсы,

Компонент принимает два пропса:

1. text: Текст сообщения, который будет отображен.

2. isMyMessage: Булевый флаг, указывающий, является ли сообщение "моим" (отправленным текущим пользователем) или "чужим" (полученным от другого пользователя).



Рендеринг

1. <div>: Основной контейнер для сообщения. Его класс зависит от значения isMyMessage:

2. Если isMyMessage равно true, добавляется класс my-message.

3. Если isMyMessage равно false, добавляется класс other-message.

4. <p>: Текст сообщения, который передается через пропс text.

# InputBox.jsx

Пропсы,

Компонент принимает один пропс:

1. onSendMessage: Функция, которая вызывается при отправке сообщения. Она принимает текст сообщения в качестве аргумента.



Состояние:

1. message: Состояние, которое хранит текущий текст сообщения, введенный пользователем.

2. setMessage: Функция для обновления состояния message.



Функция handleSend:

Эта функция вызывается при нажатии на кнопку "Отправить".

1. Проверка текста: Если текст сообщения не пустой (после удаления пробелов с помощью trim), вызывается функция onSendMessage с текстом сообщения.

2. Очистка поля ввода: После отправки сообщения поле ввода очищается с помощью setMessage('').



Рендеринг:

1. <input>: Поле ввода текста. Его значение привязано к состоянию message, а изменение текста обрабатывается с помощью onChange.

2. <button>: Кнопка для отправки сообщения. При нажатии вызывается функция handleSend.

# AuthForm.jsx

— это форма для ввода данных, необходимых для аутентификации и начала работы с Green API. 

Он позволяет пользователю ввести idInstance, apiTokenInstance и номер телефона получателя, после чего передает эти данные в родительский компонент через пропс onAuth.

Пропсы,

Компонент принимает один пропс:

1. onAuth: Функция, которая вызывается при успешной отправке формы. Она принимает объект с данными формы.



Состояние:

Компонент использует три состояния для управления полями формы:

1. idInstance: Хранит значение поля для ввода idInstance.

2. apiTokenInstance: Хранит значение поля для ввода apiTokenInstance.

3. recipientPhone: Хранит значение поля для ввода номера телефона получателя.



Функция handleSubmit:

Эта функция вызывается при отправке формы.

1. e.preventDefault(): Предотвращает стандартное поведение формы (перезагрузку страницы).

2. Проверка данных: Если все поля заполнены (после удаления пробелов с помощью trim), вызывается функция onAuth с объектом, содержащим данные формы.



Рендеринг:

1. Заголовок формы.

2. Форма с тремя полями ввода и кнопкой отправки.

3. Поля для ввода idInstance, apiTokenInstance и номера телефона получателя. Их значения привязаны к состоянию, а изменения обрабатываются с помощью onChange.

4. required: Поля обязательны для заполнения.

5. Кнопка для отправки формы.
